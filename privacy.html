Política de privacidad

Angst Feeder es una aplicación personal de uso privado, operada por su único propietario (cuenta de GitHub cipinzas-hash). No tiene registro de usuarios ni público general.

Datos de Google que se usan

La aplicación solicita el permiso https://www.googleapis.com/auth/calendar.events sobre la cuenta de Google de su propietario. Lo usa únicamente para crear, actualizar y eliminar eventos en el calendario familiar del propietario, y para leer los eventos de ese calendario y mostrarlos en su planner personal.

Qué no se hace

Los datos de Google no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial. El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Almacenamiento

Las credenciales de acceso se guardan como secretos cifrados de GitHub Actions. Los datos del planner residen en un repositorio privado del propietario.

Revocar el acceso

El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.

Cambios y contacto

Esta política puede actualizarse; la versión vigente es la publicada en esta página. Para consultas, abre un issue en el repositorio cipinzas-hash/feeder.
